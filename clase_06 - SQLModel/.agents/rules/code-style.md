# Estándar de Código de Python

## Formato y Estilo
- Usa nombres en **camelCase** para funciones, variables y métodos (ej. `get_country_by_id`).
- Usa nombres en **PascalCase** para las clases (ej. `CountryController`).

## Documentación
- Agrega un *docstring* breve al inicio de cada clase o método explicando qué hace, siguiendo el estándar de Google.
